# Pallavi Sankar — Portfolio

Personal portfolio website built with vanilla HTML, CSS.

🔗 **Live Site:** [my_portfolio](https://pallavi-sankar.netlify.app/)

---

## About

A minimal, dark-themed portfolio showcasing my projects, skills, certifications, and experience as a final-year CS student at VIT-AP.

## Built With

- HTML5 · CSS3 · Vanilla JavaScript
- Google Fonts (Cormorant Garamond, DM Mono)
- No frameworks, no dependencies

## Sections

- Hero — intro, role pills, quick links
- About — profile summary, open-to, location
- Skills — languages, core focus
- Projects — end-to-end academic projects
- Education — degrees and scores
- Certifications 
- Contact — email, LinkedIn, GitHub

## Deploy

Hosted via **Netlify** .

---

## How to Run Locally

Just open the file in your browser — no build step needed.

```bash
git clone https://github.com/palla-vii/portfolio.git
cd portfolio
open index.html
```
